# Socius 0.1.0 Beta 2

A little desktop companion with a pocket of useful tools.

This update adds a native app icon and separates development data and onboarding preferences from installed releases. Existing release data stays intact.

- Feed, play with, name, and move your pet; it rests at the screen edge when you’re done.
- Keep files, clipboard history, notes, and snippets within reach.
- Control Spotify Desktop and system volume.
- Read Codex and Claude account limits through installed CLIs.
- Save and restore window layouts with Accessibility permission.
- Customize quiet mode, visible tools, and the shortcut that brings your pet to the cursor.

## Install

Requires an Apple Silicon Mac running macOS 15 or later. Open the DMG and drag Socius into Applications. Launch it to meet your pet. The default summon shortcut is Control–Option–M.

## Beta notes

- Spotify Desktop is required for Music; browser players are not supported yet.
- AI Credits requires signed-in provider CLIs, or the explicit Claude Keychain fallback when its CLI is absent. Claude’s terminal-based usage integration can require maintenance as its CLI changes.
- Window layouts restore applications and available window positions, not documents or browser tabs. macOS may require Accessibility permission.
- Updates are manual: download a new release and replace the app.

Pocket tools reuse MIT-licensed Cyclop code: https://github.com/akalikbergenov/cyclop
