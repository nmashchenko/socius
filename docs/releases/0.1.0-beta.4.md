# Socius 0.1.0 Beta 4

A more reliable desktop pet, pocket, and developer dashboard.

- Drag the pet down to the physical bottom of the display. Release and later edge travel retain its placement, including across displays.
- The pet hides after 10 seconds without interaction and peeks every 30 seconds. A stationary pointer after dragging and clicks in other apps no longer keep restarting its idle timer.
- Fullscreen apps and videos hide the pet and pocket; the pet returns in place when fullscreen ends.
- Spotify remains visible when another app owns macOS Now Playing. Playback controls address Spotify directly, and Automation access errors include recovery guidance.
- Snippets restores Cyclop’s compact spacing, trailing icons on hover, and highlight animation. Native fields support Return/Escape and save row edits when focus leaves.
- Onboarding shares the desktop pet, keeps its tentacles moving after arrival, and handles closing, hiding, and replay without duplicate pets.
- The developer dashboard now controls the single desktop pet. Care, appearance, idle/reminder actions, and timing presets affect that pet directly.
- Pet size adapts to the display, with an adjustable size setting and four color choices. Pockets reposition after resizing. Sleeping has a curled pose and inward bubbles; macOS Reduce Motion remains supported.
- Summon-shortcut setup handles unavailable combinations without losing the previous shortcut. Pet clicks add 2 happiness.
- Screenshot watching reports folder access and stops cleanly when its folder is removed or renamed. Clipboard pause cancels pending captures; closing the pocket resets privacy reveals.
- Notes and Snippets protect unreadable or externally changed data. Claude CLI discovery covers common installation paths; Codex cancellation cleans up promptly. AI connection diagnostics can be copied without credentials or raw command output.
- Runtime logs use Socius branding. Development builds keep separate data and permission identities.

## Install

Requires Apple Silicon and macOS 15 or later. Quit Socius, open the DMG, and replace Socius in Applications. Existing release tool data and preferences are preserved. Updates remain manual.

Music requires Spotify Desktop and may request Automation access to Spotify. Layouts needs Accessibility access. Screenshot watching uses a folder picker. Fullscreen detection does not require Accessibility or Screen Recording permission.

Pet care state still resets on relaunch. Browser media controls are not included. Pocket tools reuse MIT-licensed Cyclop code; attribution remains included in the app.
