# Socius 0.1.0 Beta 3

Improved first-time permission setup.

- Window layouts show one Accessibility prompt, rather than opening two permission interfaces at once.
- Socius checks for newly granted access while you are in System Settings and when you return. Reopening Layouts also refreshes access.
- The screenshot-folder picker stays above the floating pocket and uses Socius branding.
- Screenshot watching reports success only after the folder can be read and watched. Failed access shows a recovery message.

## Install

Requires Apple Silicon and macOS 15 or later. Quit Socius, open the DMG, and replace Socius in Applications. Your release data and preferences are preserved.

Layouts needs Accessibility access. Screenshot watching uses a folder picker and does not require Accessibility. If you previously used a locally signed development build, macOS may require removing its old Accessibility entry and adding the installed app once.

Updates remain manual. Music requires Spotify Desktop. Browser players are not supported yet.
